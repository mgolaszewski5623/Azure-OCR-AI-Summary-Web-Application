# Azure-OCR-AI-Summary-Web-Application
Aplikacja webowa ASP.NET MVC wykorzystująca usługi Microsoft Azure do przetwarzania obrazów, ekstrakcji tekstu (OCR), generowania podsumowań AI oraz eksportu wyników do pliku PDF. Projekt demonstruje praktyczne użycie Azure Computer Vision, Azure OpenAI (Foundry), Azure Blob Storage oraz Azure Cosmos DB.
